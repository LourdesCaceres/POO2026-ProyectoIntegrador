# POO2026-ProyectoIntegrador
Práctico Integrador (TP7) de POO 2026. Gestión de Biblioteca en Java: socios (estudiantes y docentes), libros y préstamos, con herencia, polimorfismo y colecciones genéricas. Desarrollo en equipo.

## Estructura del repositorio
```text
POO2026-ProyectoIntegrador/
|--- Gestion-Biblioteca/
|    |--- clases.md
|--- decisiones-disenio.md
|--- README.md
```
### Contenido
* `Gestion-Biblioteca/`: carpeta donde se encuentran todos los archivos .java
* `clases.md`: documento con la distribución (en subgrupos) de las clases del proyecto.
* `deciciones-disenio.md`: único documento, para registrar las decisiones de diseño acordadas por el equipo.
